**平行**是为 SCP-CN 维基制作的 CSS 主题，是玄武岩基础版式**基岩**的深度修改版本，便于 Dr Hormress 二次开发使用，提供一个具有工作感的视觉外观和多个预制配色方案。**平行**的最初目的并不是直接被引入，不过的确任何用户可以这么做。

另请参阅：https://scp-wiki-cn.wikidot.com/theme:parallel
